2. Dados que coletamos

O Numen foi desenhado com privacidade em mente. Não criamos contas de usuário, não pedimos login e não coletamos dados pessoais identificáveis (nome, e-mail, telefone, foto, localização, contatos, etc.).

Os únicos dados manipulados pelo aplicativo são:

2.1. Dados de progresso (armazenamento local)

Seu progresso no aplicativo — fases concluídas, estrelas, melhores tempos, vidas restantes, módulos premium desbloqueados e preferências de onboarding — é armazenado exclusivamente no seu próprio dispositivo. Esses dados nunca são enviados para nossos servidores nem para terceiros.

2.2. Conteúdo enviado à funcionalidade "Resolução por IA"

Quando você utiliza a funcionalidade de Resolução por IA, o texto da questão e a alternativa correta são enviados aos servidores da Anthropic (provedor da inteligência artificial Claude) para geração da explicação passo a passo. Não enviamos nenhuma informação adicional além do conteúdo da questão. Os termos de privacidade da Anthropic podem ser consultados em anthropic.com/legal/privacy.

2.3. Mensagens de reporte de bugs

Quando você utiliza o botão "Reportar Bug", a mensagem que você escrever, somada ao identificador técnico da questão (quando aplicável), plataforma do dispositivo (Android/iOS) e data/hora do envio, é encaminhada ao nosso e-mail de suporte através do serviço Formspree (formspree.io). Não coletamos nenhuma outra informação automaticamente.

2.4. Dados de pagamento (compras dentro do app)

As compras dos módulos premium e demais itens pagos são processadas diretamente pela Apple (App Store) ou Google (Google Play). Nós não recebemos, armazenamos nem temos acesso a dados de cartão de crédito, conta bancária ou qualquer informação financeira sua. Apenas recebemos das lojas a confirmação de que a compra foi aprovada para liberar o conteúdo correspondente.

3. Para que usamos os dados

  • Dados de progresso: ficam no seu dispositivo para que você não perca seu avanço entre sessões.
  • Conteúdo enviado à IA: exclusivamente para gerar a explicação solicitada.
  • Mensagens de bug: para corrigir falhas e melhorar a qualidade do aplicativo.
  • Confirmação de compra: para liberar o conteúdo premium adquirido.

5. Anúncios, tracking e analytics

O Numen não exibe anúncios, não utiliza identificadores de publicidade (IDFA, AAID), não usa cookies e não integra serviços de analytics (como Google Analytics, Firebase Analytics, Facebook SDK, etc.).

6. Crianças

O Numen é classificado como apropriado para todas as idades (4+). Ainda assim, como não coletamos dados pessoais de nenhum usuário, não há tratamento específico de dados de crianças e adolescentes além do já descrito nesta política.

7. Seus direitos (LGPD)

A Lei Geral de Proteção de Dados (Lei nº 13.709/2018) garante a você os seguintes direitos:

  • Confirmação da existência de tratamento de dados
  • Acesso aos dados
  • Correção de dados incompletos, inexatos ou desatualizados
  • Anonimização, bloqueio ou eliminação de dados
  • Portabilidade dos dados
  • Eliminação dos dados tratados com seu consentimento
  • Informação sobre compartilhamento
  • Revogação do consentimento

Como o Numen não armazena dados pessoais em nossos servidores, a maioria desses direitos é exercida diretamente por você: para apagar todos os dados de progresso, basta desinstalar o aplicativo. Para qualquer outra solicitação ou dúvida, entre em contato pelo e-mail larisfinancialservices@gmail.com.

8. Segurança

Os dados de progresso ficam armazenados no seu dispositivo e estão protegidos pelos mecanismos de isolamento de aplicativos do sistema operacional (iOS/Android). As comunicações com a API da Anthropic e com o Formspree são feitas por meio de conexões criptografadas (HTTPS/TLS).
